# IoT für nachhaltige Lieferketten von Lithium-Ionen-Batterien

**Webseite mit Prototyp zum Ausprobieren:** https://tbayrem.github.io/iot-nachhaltige-lieferkette-batterien/

Seminararbeit (M.Sc. Wirtschaftsinformatik, Hochschule Worms, 18.11.2024 bis 15.01.2025, Betreuung: Prof. Dr. Elisabeth Heinemann) von Bayrem Trabelsi.

## Forschungsfrage

Wie können IoT-Technologien die ökologischen, ökonomischen und sozialen Herausforderungen in der Lieferkette von Lithium-Ionen-Batterien bewältigen?

## Inhalt

- Nachhaltigkeitsanalyse der Batterie-Lieferkette (Drei-Säulen-Modell)
- IoT-Technologien: WSN, RFID, Middleware, Cloud
- Fallbeispiel Stellantis (Fiat 500e): Echtzeitüberwachung mit Edge Computing und KI
- Diskussion: Transparenz und Sicherheit

## Grenzen

Reine Literaturarbeit. Der Fallstudie liegt eine Forschungsarbeit zugrunde, der Nachhaltigkeitseffekt ist nicht quantifiziert.
